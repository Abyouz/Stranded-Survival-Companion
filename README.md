## 🚀 Core Concept

Strandforge Toolkit is **not** a traditional trainer in the conventional sense. It is a **modular enhancement layer** that sits alongside the game, offering a palette of optional tweaks that players can toggle individually. Rather than flipping a single "god mode" switch, users can sculpt their experience with granularity.

The toolkit is built around three pillars:

1. **Traversal Enhancement** — Reduce the tedium of long deliveries without removing the challenge of terrain.
2. **Resource Fluidity** — Manage chiral bandwidth, stamina, and cargo weight with more grace.
3. **Combat Calibration** — Adjust encounter difficulty to match your preferred pacing.

Each pillar is independent, and users can enable or disable any combination they wish.

### 🏃 Traversal & Movement
- **Endurance Reservoir** — Stamina drains at a fraction of the default rate, letting you sprint across the map without constant breaks.
- **Weightless Carrying** — Cargo mass is dramatically reduced, allowing you to haul more without tipping over.

- **Bandwidth Relief** — Chiral network bandwidth cap is raised, letting you build more structures.

## 🧩 Modular Architecture

The toolkit is organized into independent modules. Each module can be compiled or disabled separately:

| Module | Purpose |
|--------|---------|
| `strandforge-core` | Base injection and memory management |
| `strandforge-traversal` | Movement and stamina adjustments |
| `strandforge-survival` | Health and damage handling |
| `strandforge-network` | Chiral bandwidth and structure sync |
| `strandforge-combat` | Damage and stealth calibration |
| `strandforge-ui` | Overlay rendering and configuration |

This modularity ensures that users only load what they need, reducing the footprint and potential conflicts.
